# 사이버보안 학습 포트폴리오

컴퓨터네트워크 및 네트워크 보안 수업 실습과 Python 개인 학습 프로젝트를 정리한 한국어 정적 사이트입니다. [Astrofy](https://github.com/manuelernestog/astrofy)의 레이아웃과 DaisyUI 구성 요소를 사용합니다.

- 사이트 정보: `src/profile.json`
- 콘텐츠: `src/pages/`
- 정적 자산: `public/`
- 배포: `.github/workflows/deploy.yml`

템플릿 라이선스는 `LICENSE`에 포함되어 있습니다.
